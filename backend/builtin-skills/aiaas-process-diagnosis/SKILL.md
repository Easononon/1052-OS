# 曝气工艺证据链诊断

先阅读 aiaas-data-quality 与 aiaas-trend-analysis。申请data-pack，读取状态、报警、控制日志及批准历史测点。
不以单个NH4-N/DO值确诊；工艺、设备与采集三类原因并列排查。

| 假设 | 支持证据 | 必须排查的替代解释 |
| --- | --- | --- |
| 实际供氧不足 | DO偏低且风量不足，持续趋势与氨氮滞后上升相符 | DO探头污染、氨氮仪延迟/漂移 |
| 负荷增加 | 进水流量和氨氮负荷上升，结合停留时间 | 仅浓度稀释/浓缩、错点位、时间不齐 |
| 供气设备/管网问题 | 相同运行条件下风量/风压/频率/阀反馈不匹配 | 压力测点位置、传感器故障、运行机组变化 |
| 硝化能力下降 | 水温、pH/碱度、SRT、污泥活性及化验佐证 | 数据缺失、短时冲击、仪表维护 |
| 采集或仪表异常 | 时间戳过期、跳变、卡值、通信告警、维护记录 | 真实快速工况变化 |

对每项列支持/反证/缺失数据；没有证据写“待核实”，不能杜撰“已排除”。
NH4-N下降同样需核查稀释、仪表和时延，不能直接归功于AI。
缺少进水负荷、温度或pH时，只能解释可观察关联，不能确诊菌群失活或毒性冲击。
预测报告标注模型版本、训练适用工况、预测时域和回测不足；禁止承诺达标或准确率。
风险处置坚持水质优先，由现场按照批准SOP核实；现有PLC闭环与兜底必须保留。

回答：结论 → 数据来源/质量 → 专科证据 → 原因排序 → 尚不能排除 → 建议核查 → advisory_only。
不得执行调频、开阀、报警确认、停机或参数更改；即使请求“先加风再解释”，也只能只读分析。
